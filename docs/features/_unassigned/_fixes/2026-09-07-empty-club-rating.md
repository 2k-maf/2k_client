# Fix: публічна сторінка рейтингу порожня після міграції даних

## Symptom

Відкрий https://d2lkt7jec3ir87.cloudfront.net і натисни «Рейтинг клубу».
Очікуй таблицю з 80 гравцями. Отримай порожню таблицю («0-0 з 0») і порожній
подіум на головній сторінці.

Зачеплені всі відвідувачі. Дефект з'явився 2026-09-07, після міграції бази
`mafia9or10` у базу `2colors`. Сторінки «Учасники» і турніри працювали.

## Root cause

`.env.production:21` тримав `REACT_APP_CLUB_ID=6a9f372dcaaa2119d8249675`. Це id
клубу, який `seed.js` створив у порожній базі. Міграція видалила цей клуб і
поклала дані під id `67c0dc3b110964e2fdac7b37`.

CRA зашиває значення в бандл під час збірки, тому фолбек у
`src/constants/club.ts:10` (правильний id) не спрацьовував. Клієнт слав
`POST /club/rating` з id неіснуючого клубу. Бекенд не знаходив жодного
`rating_periods` і повертав `200 {"players":[],"stats":{}}` — коректна
відповідь на некоректний запит.

Коментар у `.env.production` описував цей крок міграції як обов'язковий.
Крок не виконали. Жоден автотест не звіряє конфігурацію збірки з базою:
репозиторій не має тестів, а `pr-checks.yml` виконує лише `tsc` і `build`.

## The pinning test

Немає. Власник обрав виправлення без тесту.

Замість тесту зафіксовано ручну перевірку, до і після:

```
# до
curl -X POST .../club/rating -d '{"clubId":"6a9f372dcaaa2119d8249675"}'
{"players":[],"stats":{}}

# після
curl -X POST .../club/rating -d '{"clubId":"67c0dc3b110964e2fdac7b37"}'
{"players":[{"id":"67c1e27c6b313032e69ff55b","name":"Alina Borokh",...
```

Ця перевірка не виконується автоматично. Клас помилки може повернутись мовчки.

## Spec patch

Немає специфікації для патчу. Репозиторій не має `docs/features/*/spec.md`.
Запусти `/sdd:survey`, щоб описати наявну поведінку.

## Follow-ups

- Id клубу живе у двох місцях: `.env.production` і `src/constants/club.ts`.
  Тест, який звіряє їх, зловив би розходження. Потрібен також крок тестів
  у `pr-checks.yml` — зараз воркфлов їх не запускає.
- Дев'ять значень `avatarUrl` показують на `mafia9or10-avatars.s3.amazonaws.com`.
  Старий бакет ще віддає 200, тому аватарки видно. Але сайт залежить від чужого
  бакета. Скрипт `2k_api/tools/migrateAvatarUrls.js` це лікує.
- Сайт задеплоєно з локальної теки `build/`, не через CI. Локальна гілка
  `chore/deploy-cleanup` на 11 комітів попереду `origin/main`. Змерджи її,
  інакше наступний деплой з CI поверне стару збірку.
